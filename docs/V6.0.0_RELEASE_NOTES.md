# V6.0.0 正式版发布说明

发布日期：2026-09-14

## 正式能力

- 课程、章节、课表与校历管理，支持节假日、调休和按指定日期补班。
- 全量唯一课堂材料处理；长转写自动规范化、强制切片和保序分段。
- Lesson Understanding、Student Simulator、Composer V2 学习内容生产链。
- Evidence V2 逐 claim 来源绑定和生产者可见性校验。
- Coverage Ledger、Coverage Auditor 与质量门禁，禁止静默丢弃后伪报成功。
- 课堂笔记、复习讲义的结构化 HTML、PDF 和 Obsidian 输出。
- 作业、错题、掌握状态与复习联动。
- 本地多模型网关、候选模型回退、调用审计和前端模型管理。

## 大材料与超时策略

- 常规课堂理解段默认控制在约 12,000 输入 Token。
- 无标点超长文本会在规范化阶段强制切片。
- 课堂分段请求读取等待上限为 600 秒。
- 读取超时不会对同一请求机械重放三次，而是交给 DAG 切换候选模型。
- 原材料覆盖由账本独立记录，分段不会改变材料域。

## 发布验收

- 后端必须通过 `backend/tools/run_tests_isolated.py`。
- 前端必须通过 `npm run build`，包含 `vue-tsc` 和 Vite 生产构建。
- 隔离测试必须保持正式数据库 SHA-256、修改时间与文件长度不变。
- 隔离测试禁止访问真实网关。
- 正式入口由 FastAPI 同源托管 `frontend/dist`，根路径必须返回 SPA。
