## 一、P0-A：安全加固

### 1.1 Token 保护范围扩展到所有非白名单 API 接口

**当前代码 backend/app/main.py：**

```python
_TOKEN_PROTECTED_PREFIXES = (
    "/api/mobile",
    "/api/materials/upload",
    "/api/workflows/",
)
```

**问题：** Funnel 公网下 GET /api/courses、GET /api/runs、GET /api/rag/search 未受保护。

**修改为：**

```python
# 公开白名单——只有这些路径允许匿名访问
_PUBLIC_PATHS = {
    "/api/mobile/server-info",
}

@app.middleware("http")
async def mobile_token_check(request: Request, call_next):
    path = request.url.path
    if not path.startswith("/api/"):
        return await call_next(request)

    # admin token 管理有本机保护
    if path.startswith("/api/admin/mobile-token"):
        return await call_next(request)

    # server-info 匿名
    if path in _PUBLIC_PATHS:
        return await call_next(request)

    # 本机 127.0.0.1 / ::1 不拦截；其它来源必须带 token
    client_host = request.client.host if request.client else ""
    is_local = client_host in ("127.0.0.1", "::1")
    if config.MOBILE_TOKEN and not is_local:
        provided = (
            request.headers.get("x-app-token", "")
            or request.query_params.get("token", "")
        )
        if provided != config.MOBILE_TOKEN:
            return JSONResponse(
                status_code=403,
                content={"detail": "凭证无效，请在 URL 后添加 ?token=xxx 或设置 x-app-token header"},
            )
    return await call_next(request)
```

### 1.2 上传接口安全

**当前问题：**

## 二、P0-B：LLM 路由与 fallback 修复

### 2.1 DAGNode 路由重构（dag.py）

**当前核心 bug：**

```python
models = self.preferred_models or [ctx.resolve_model(self.agent_role)]
```

只要节点写了 preferred_models，quota 路由结果不会生效。

**新逻辑：**

```python
@dataclass
class DAGNode:
    name: str
    agent_role: str
    handler: Callable[["DAGContext", str], Awaitable[dict]]
    preferred_models: list[str] = field(default_factory=list)
    fallback_models: list[str] = field(default_factory=list)
    depends_on: list[str] = field(default_factory=list)

    async def run(self, ctx: "DAGContext") -> dict:
        # 1. primary = ctx.resolve_model (已带 quota 路由)
        primary = ctx.resolve_model(self.agent_role)
        if not primary and self.preferred_models:
            primary = self.preferred_models[0]

        # 2. fallback = [primary] + fallback_models + preferred_models (去重)
        candidates = list(dict.fromkeys(
            [primary, *self.fallback_models, *self.preferred_models]
        ))
        # 3. 依次尝试
        ...
```

### 2.2 DAG 定义改为 fallback_models

| 文件/节点 | 旧写法 | 新写法 |
|---|---|---|
| homework/solver | preferred_models=["deepseek_v4_free","deepseek_v4_official"] | fallback_models=["deepseek_v4_official"] |
| homework/vision_reader | preferred_models=["qwen3_vl"] | fallback_models=[] |
| lesson/vision_reader | preferred_models=["qwen3_vl","minimax_m3"] | fallback_models=["minimax_m3"] |
| lesson/student_simulator | [...] | fallback_models=["official","qwen3_8_27b"] |
| lesson/note_writer | [...] | fallback_models=["official","qwen3_8_27b"] |
| lesson/critic | [...] | fallback_models=["minimax_m3"] |

> **说明：** fallback_models 的语义是“当 current route primary 失败后的后备模型”。若希望保留旧的显式首选模型行为，可以把旧 preferred_models 第二项以后移到 fallback_models。resolve_model(role) 返回的 primary 无论来源如何，都必须作为第 1 候选。

### 2.3 handler 不再吞掉可恢复异常

**原则：**

| 异常 | 处理 |
|---|---|
| 网关超时 / 5xx / 429 | 抛 GatewayRetryableError -> DAG fallback |
| JSON 解析失败 / schema 缺失 | 抛 SchemaValidationError -> 重试 |
| 业务输入不合法 | 抛 BusinessError -> fail |
| 本地占位可展示 | 标记 degraded 而不是 success |

**需要去掉吞异常的 handler：**

- dag_lesson.py 的 student_simulator / note_writer 的 except -> return fallback
- dag_homework.py 的 homework_solver 的 except -> append 求解失败

## 三、P0-C：Agent 节点真实化

### 3.1 vision_reader 不再返回 `[待视觉识别]` 哑数据

**当前代码 backend/app/dag_homework.py：**

```python
async def homework_vision_reader(ctx: DAGContext, model_id: str) -> dict:
    images = ctx.input.get("images", []) or []
    results = []
    for img in images:
        results.append({"image": img, "text": "[待视觉识别]", "confidence": 0.0})
    return {"results": results}
```

**问题：** 永远返回占位文本，即使模型是 qwen3_vl 也没有真正调用视觉模型。

**修改方案：**

```python
async def homework_vision_reader(ctx: DAGContext, model_id: str) -> dict:
    images = ctx.input.get("images", []) or []
    results = []
    total_in = total_out = 0
    for idx, img in enumerate(images):
        if not img:
            continue
        # 优先读取本地图片文件；若不是本地路径则原样传递
        image_b64 = _load_image_b64(img)  # 复用工具函数
        prompt = (
            "请识别这张作业图片中的题目内容。\\n"
            "输出要求：\\n"
            "1. 原样转写文字（保留数学符号、下标、编号）\\n"
            "2. 若包含图片标注，说明图片内容\\n"
        )
        messages = [
            {"role": "system", "content": "你是 OCR 题目转写助手，只输出 JSON。"},
            {"role": "user", "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_b64}"}}
            ]}
        ]
        from .gateway import gateway
        resp = await gateway.chat(model_id, messages, temperature=0.2)
        _ = None
        from .reasoning import extract_json
        data = extract_json(resp.get("content", "")) or {}
        text = data.get("text") or data.get("transcription") or ""
        total_in += resp.get("tokens_in", 0)
        total_out += resp.get("tokens_out", 0)
        if not text.strip():
            raise GatewayRetryableError(f"vision_reader 返回空文本: image#{idx}")
        results.append({"image": img, "text": text,
                         "confidence": float(data.get("confidence", 0.85))})
    if not results:
        return {"results": [], "error": "没有可识别的图片"}
    return {"results": results,
            "tokens_in": total_in, "tokens_out": total_out}
```

**落地配套：**
- `_load_image_b64()`：读本地文件 → base64，文件不存在则返回空字符串。
- gateway.chat 需支持多模态消息（qwen3_vl 已具备，网关侧确认一下即可）。
- 视觉识别失败时**不吞异常**，直接 raise `GatewayRetryableError`，让 DAGNode 自动 fallback。

### 3.3 solution_explainer 教学化改写真实化

**当前 (dag_homework.py)：**

```python
async def homework_explainer(ctx: DAGContext, model: str) -> dict:
    return {"reviewed_items": ctx.outputs.get("solver", {}).get("answers", [])}
```

**问题：** 直接把 solver 答案透传，没有教学化改写，也没有比对 parallel_solver。

**修改方案：**

```python
async def homework_explainer(ctx: DAGContext, model: str) -> dict:
    # 1. 合并 solver + parallel_solver 两路结果
    solver_items = ctx.outputs.get("solver", {}).get("answers", []) or []
    parallel = ctx.outputs.get("parallel_solver", {}).get("parallel_answers", []) or []
    by_question = {it["question_no"]: it for it in solver_items}

    reviewed = []

        item = by_question[qno]

        teaching = extract_json(resp.get("content", "")) or {}
        reviewed.append({**item, **teaching})
    return {"reviewed_items": reviewed}
```

### 3.4 evidence_checker 硬 Gate（阻断无证据的答案）

**当前 (dag_homework.py)：**

```python
async def homework_evidence(ctx: DAGContext, model: str) -> dict:
    items = ctx.outputs.get("explainer", {}).get("reviewed_items", [])
    return {"evidence_status": "ok", "items": items}
```

**问题：** 永远返回 ok，没有任何校验。审阅意见指出"evidence 硬 Gate"缺失——作业解答可以不基于任何来源材料就得到"通过"。

**修改方案：**

```python
async def homework_evidence(ctx: DAGContext, model: str) -> dict:
    """逐题做证据硬校验：可引用的 chunk_id 必须真实存在，quote 必须出现在 chunk.text 中。"""
    from .database import query
    items = ctx.outputs.get("explainer", {}).get("reviewed_items", []) or []
    checked = []
    for item in items:
        evidence_list = item.get("evidence", []) or []
        verified_list = []
        for ev in evidence_list:
            chunk_id = ev.get("chunk_id")
            quote = ev.get("quote", "")
            # 1. chunk 真实存在
            row = query("SELECT id, text FROM source_chunks WHERE id=?", (chunk_id,), one=True)
            if not row:
                verified_list.append({**ev, "verified": False, "reason": "chunk_id not found"})
                continue
            # 2. quote 文本包含在 chunk.text 里
            if quote and quote in (row.get("text") or ""):
                verified_list.append({**ev, "verified": True})
            else:
                verified_list.append({**ev, "verified": False, "reason": "quote mismatch"})
        ok_count = sum(1 for v in verified_list if v["verified"])
        # 硬 Gate：必须至少 1 条 verified evidence
        if not verified_list or ok_count == 0:
            item["evidence_status"] = "blocked"
            item["block_reason"] = "缺少通过校验的证据，无法确认答案来源"
        else:
            item["evidence_status"] = "ok"
        item["evidence"] = verified_list
        checked.append(item)
    return {"evidence_status": "ok" if all(it.get("evidence_status")=="ok" for it in checked) else "partial",
            "items": checked}
```

**配套变更：** explainer 的 prompt 必须要求输出 `evidence:[{chunk_id, quote}]`；否则 evidence_checker 会直接 `blocked`。

## 四、P1-A：数据与工程加固

### 4.1 数据库唯一约束与级联删除

**当前 backend/app/database.py：** 所有表仅外键 REFERENCES，没有 UNIQUE 约束，也没有 ON DELETE CASCADE。

**问题（审阅编号十六）：**
- courses.name 可重复插入，导致"光学/Optics"重复记录。
- chapters 删除课程后残留孤儿记录。
- materials.file_hash 无唯一索引，同一文件可上传多次。

**修改方案：** 新增 backend/app/migration.py 迁移函数：
1. 清理重复数据（先删后建索引）;
2. 创建唯一索引;
3. 重建关键表以启用 ON DELETE CASCADE。

```sql
-- 课程唯一性（name + semester）
DELETE FROM courses WHERE id NOT IN
  (SELECT MIN(id) FROM courses GROUP BY name, semester);
CREATE UNIQUE INDEX IF NOT EXISTS idx_courses_name_semester
  ON courses(name, COALESCE(semester, ''));

-- 材料去重（file_hash 非空才唯一）
CREATE UNIQUE INDEX IF NOT EXISTS idx_materials_hash
  ON materials(file_hash) WHERE file_hash IS NOT NULL AND file_hash != '';

-- 章节在同课程下编号唯一
CREATE UNIQUE INDEX IF NOT EXISTS idx_chapters_course_no
  ON chapters(course_id, chapter_no) WHERE chapter_no IS NOT NULL;
```

**注意：**
- 外键 CASCADE 在 SQLite 里必须表重建才有完整效果；对已有库建议备份后重建 chapters/lessons/materials/notes/questions/answer_items 等表。
- 迁移文件建议在 backend/app/migration.py 中提供 run_migrations()，在 run.py 启动时自动执行。

### 4.2 状态机白名单流转

**当前问题：** workflow_runs.status 可被任意 UPDATE，没有状态机约束。

**修改方案：** 在 backend/app/main.py 增加统一状态迁移 helper：

```python
ALLOWED_TRANSITIONS = {
    "pending": {"running", "cancelled"},
    "running": {"completed", "failed", "cancelled"},
    "completed": set(),
    "failed": set(),
    "cancelled": set(),
}

def can_transition(old: str, new: str) -> bool:

```

所有 workflow_runs.status 写操作（DAGContext.finish_run、取消/重跑接口）先校验，非法返回 409。

### 4.3 SQLite 安全备份

**当前 backup.py** 用 shutil.copy2，数据库文件打开时复制可能不一致。

**修改方案：** 使用 sqlite3.Connection.backup()：

```python
import sqlite3
from pathlib import Path
from .config import DB_PATH

def backup_db(dest=None):
    dest = dest or Path(str(DB_PATH) + ".bak")
    src = sqlite3.connect(str(DB_PATH))
    dst = sqlite3.connect(str(dest))
    try:
        src.backup(dst)
        dst.commit()
    finally:
        dst.close()
        src.close()
    return dest
```

## 五、P1-B：中文 RAG 完善

### 5.1 中文分词替换 split()

**当前 backend/app/rag.py：**

```python
def _tokenize(text: str) -> set[str]:
    tokens = set()
    for word in str(text).split():
        clean = re.sub(r"[^\w一-鿿]", "", word)
        if clean:
            tokens.add(clean.lower())
    return tokens
```

**问题（审阅编号十五）：** 中文没有空格，text.split() 会把整句当作一个 token，Jaccard 分数几乎永远为 0。

**修改方案：** 引入 jieba：

```bash
pip install jieba
```

```python
# backend/app/rag.py 顶部新增
import jieba

def _tokenize(text: str) -> set[str]:
    tokens = set()
    # 中文用 jieba 精确模式切词；英文/数字保持分割
    for word in jieba.cut_for_search(str(text)):
        clean = re.sub(r"[^\w一-鿿]", "", word)
        if clean:
            tokens.add(clean.lower())
    return tokens
```

**效果：** "光学透镜成像" 会被切成 {"光学", "透镜", "成像", "学透", ...} 等候选，中文检索命中率大幅提升。

### 5.2 检索逻辑增强

除 Jaccard 外，可加一个简单加权分：

```python
def _score(query_tokens, doc_tokens, doc_text, query_text):
    jac = jaccard(query_tokens, doc_tokens)
    # 2. 原词包含加分：query 关键短语在 doc.text 中完整出现时给显著加分
    bonus = 0.5 if any(q in text for q in query_tokens if len(q) >= 2) else 0.0
    return jac + bonus
```

## 六、P1-C：Pydantic Schema 与 API 输出约束

### 6.1 新增 backend/app/schemas.py

```python
from pydantic import BaseModel, Field

class Evidence(BaseModel):
    chunk_id: int | None = None
    quote: str = ""
    locator: str = ""
    verified: bool = False

class NoteResult(BaseModel):
    title: str
    body: str
    evidence: list[Evidence] = []

class SolverResult(BaseModel):
    question_no: int
    final_answer: str
    solution_plan: str = ""
    detailed_solution: str = ""
    confidence: float = 0.0

class ReviewResult(BaseModel):
    score: float = Field(ge=0, le=1)
    issues: list[str] = []
    suggestion: str = ""
```
